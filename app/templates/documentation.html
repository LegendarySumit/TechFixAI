Setup Guide

Get TechFixAI running in minutes

  1. Create an accountRegister at /signup and verify your email address
  2. Upload a voice reportNavigate to Upload and record or upload a .wav/.mp3 file in Japanese
  3. Review the ticketAI processes audio and creates a structured ticket within seconds
  4. Assign to developerTickets are auto-assigned based on category; you can re-assign manually
  5. Track & resolveDevelopers update ticket status; managers see live dashboard analytics

API Reference

Core endpoints

POST/api/auth/login
Authenticate user and receive JWT access token
POST/api/tickets/create
Create a new support ticket from processed audio data
GET/api/tickets
List all tickets with optional filters (status, severity, developer)
POST/api/upload/audio
Upload Japanese audio file for transcription and ticket generation
GET/api/dashboard/stats
Retrieve aggregate statistics for the management dashboard
